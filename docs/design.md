Owner's suggested tokens kept as given. Added for accessibility: a darker
control border (decorative lines are 1.5:1 and fail WCAG 1.4.11 for input
edges) and a muted ink that passes 4.5:1 on every surface. Dark theme is
espresso, not an inversion: the primary button becomes cream on espresso. No
orange anywhere; errors use a brick red. Theme: Light / Dark / Match system,
applied before first paint.

Type: Outfit (display, wordmark, timer, facts) + Figtree (interface text),
both OFL, self-hosted. Spacing 4–64; radius 10 controls, pill chips, 16
surfaces; motion 180 ms, none with reduced motion.

## Status language (kept from M1)
Icon + word, never color alone. Web shows "Timer only" for itself and
"Not paired" for devices until pairing exists. Core states for paired devices:
Protected, Not yet applied, Degraded, Not enforcing, Unknown.
