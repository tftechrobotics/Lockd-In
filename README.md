# Lockd In website upload files

Download `lockdin-site.zip` using the GitHub file-page download button. Upload that ZIP to Cloudflare Pages Direct Upload. The ZIP has three HTML pages at its root, with no extra containing folder. No build command is needed.

This is a policy/support **preview**; it does not certify Play compliance or implement backend deletion. See the visible draft notices. No Android code or main branch is changed.
