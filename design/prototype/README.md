# Clickable prototype (mock)

`template.html` is a standalone, clickable mock of the web and Android Focus experience in Cream &
Ink, published as the "Lockd In Prototype" artifact. It is a **mock**: its own small session model,
a sped-up clock, sample apps and an example schedule entry. It blocks nothing and is not the
product code (the real apps are in `apps/web` and `apps/android`).

Build the publishable file by substituting `{{WORDMARK}}` and `{{EDGE}}` with
`design/assets/wordmark.svg` and `design/assets/library-edge.svg`.
